# ذكيّ لأندرويد (Kotlin + Jetpack Compose)

نسخة أندرويد أصلية كاملة (Native) من منصة ذكيّ - نفس الباك إند والمشروع
بالضبط اللي الموقع وتطبيق iOS يستخدمونه، بس واجهة Kotlin/Compose مبنية
من الصفر مخصوصة للجوال (مو غلاف ويب).

## ⚠️ ملاحظة مهمة قبل أي شي

بنيت هذا المشروع كامل بدون بيئة أندرويد فعلية (ما فيه Android SDK/Gradle
بالجهاز اللي اشتغلت عليه) - عكس نسخة iOS اللي قدرت أبنيها وأشغّلها فعليًا
بمحاكي وأتأكد كل شي شغّال. يعني الكود هنا **مكتوب بعناية ومطابق لبنية
Kotlin/Compose الصحيحة قدر الإمكان، بس ما تأكدت من تجميعه (build) فعليًا**.

**أول خطوة لازم تسويها:** افتح المشروع بـ Android Studio (يفتحه تلقائي
يتعرف عليه) وشغّل **Build > Make Project** - أي خطأ تجميع بسيط (استيراد
ناقص، اسم دالة مختلف شوي بمكتبة) هيّن يصلحه Android Studio نفسه بالتلميحات
التلقائية (Quick Fix) خلال دقائق. البنية والمنطق العام كله صحيح ومطابق
للباك إند الفعلي، الاحتمال الأكبر للأخطاء (لو صارت) بتفاصيل صغيرة بمكتبات
خارجية (Retrofit/Socket.IO/Billing) مو بمنطق التطبيق نفسه.

## المكتبات المستخدمة

- **Jetpack Compose** + Material 3 - الواجهة كاملة
- **Retrofit + OkHttp + kotlinx.serialization** - نداءات باك إند ذكيّ
- **Supabase Auth مباشرة (REST)** - نفس مفتاح anon المستخدم بالموقع
  بالضبط (`ApiConfig.kt`) - بدون أي مكتبة Supabase SDK إضافية
- **Socket.IO Client** - غرف الدراسة اللحظية (نفس بروتوكول الموقع/iOS)
- **DataStore Preferences** - حفظ الجلسة محليًا
- **Google Play Billing** - الاشتراكات داخل التطبيق
- **Coil** - تحميل الصور

```
      library/, performance/, archive/
      rooms/            الغرف الجماعية والدروس المباشرة
      settings/         الإعدادات + الاشتراك

    values/, values-en/   النصوص (عربي افتراضي + إنجليزي)

```

## ميزات مو مكتملة ١٠٠٪ بهذا الإصدار

- **الصوت الجماعي (WebRTC) بالغرف المباشرة**: أزرار الميك موجودة وترسل
  الأحداث الصحيحة لـ Socket.IO، بس معالجة اتصال WebRTC الفعلي (SDP/ICE)
  محتاجة إكمال واختبار حقيقي على جهاز - علّمتها بتعليق واضح بـ
  `RoomScreen.kt`.
- **السبورة التفاعلية المشتركة**: نفس الوضع - البنية جاهزة (Socket.IO)
  بس شاشة الرسم نفسها (Canvas) محتاجة إضافة.
- معرّفات منتجات الاشتراك (`PlanCatalog.kt`) لازم تُنشأ فعليًا بـ
  **Google Play Console** بنفس القيم بالضبط (`zakiy_plus_monthly`... إلخ)
  قبل ما الشراء الفعلي يشتغل - نفس القيم موجودة بالباك إند
  (`GOOGLE_PRODUCT_PLAN_MAP`).

## التشغيل

1. افتح مجلد `Android/` بـ Android Studio (نسخة حديثة، Jellyfish أو أحدث).
2. خلّه يزامن Gradle تلقائيًا (يحمّل المكتبات المطلوبة).
3. شغّل على محاكي أو جهاز حقيقي (زر Run الأخضر).

كل الميزات تتصل بنفس الباك إند المباشر (`zakiy-platform.onrender.com`)
ونفس مشروع Supabase - ما يحتاج أي إعداد سيرفر إضافي.
